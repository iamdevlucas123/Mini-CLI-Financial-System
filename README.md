# Mini-CLI-Financial-System

Sistema de controle financeiro totalmente executado pelo terminal (CLI).

O projeto foi desenvolvido como um exercício prático para aplicar **Python, matemática, estruturas de dados, análise numérica e complexidade de algoritmos** em um problema real.

---

## 🎯 Objetivo

Construir um sistema financeiro capaz de controlar receitas e despesas enquanto força a aplicação prática de conceitos fundamentais de:

- Matemática
- Python
- Estruturas de Dados
- Algoritmos
- Complexidade computacional
- Análise numérica

A ideia é sair da teoria e enxergar esses conceitos funcionando em um sistema real.

---

## 💰 Funcionalidades

O sistema deverá permitir:

- Cadastrar receitas
- Cadastrar despesas
- Criar categorias
- Consultar saldo
- Calcular porcentagens
- Trabalhar com parcelas
- Calcular juros
- Converter valores
- Gerar relatório mensal
- Definir orçamento
- Comparar diferentes meses
- Consultar histórico de transações
- Buscar transações por ID
- Ordenar despesas
- Categorizar transações

# 🗃️ Estruturas de Dados

O sistema deverá implementar diferentes estruturas de dados manualmente e utilizá-las em situações reais.

## Estruturas

- Array / List
- Hash Map
- Heap
- Tree

### Aplicações

| Problema | Estrutura |
|---|---|
| Histórico de transações | Array / List |
| Buscar transação por ID | Hash Map |
| Ordenar despesas | Heap |
| Categorizar transações | Tree |

O objetivo é compreender não apenas como cada estrutura funciona, mas também **por que determinada estrutura é adequada para determinado problema**.
